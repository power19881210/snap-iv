# SNAP-IV 評量表（線上填寫）

SNAP-IV 評量表的線上版：直接點選作答、自動計分，並可下載與原紙本相同版面的 PDF（可選擇附上計分結果頁）。

## 計分方式
- **方法 A｜分量表平均分**：分量表總分 ÷ 題數（四捨五入至小數第二位），對照 Swanson 暫定 5% 切截點（父母版／老師版）。
- **方法 B｜題數**：各分區勾選「還算不少」或「非常的多」的題數，注意力不足、過動／衝動、反抗對立分別至少 6、6、4 題為建議進一步評估的標準。

量表為篩檢工具，結果不等於診斷。
